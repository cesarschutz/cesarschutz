## Recursos técnicos utilizados

- `<picture>` + `prefers-color-scheme`: troca automática de imagens entre tema claro e escuro.
- `readme-typing-svg`: texto animado digitando/apagando via SVG.
- `capsule-render`: cabeçalhos SVG com gradientes e animação.
- `github-readme-stats`: cards SVG dinâmicos com dados públicos.
- `github-readme-activity-graph`: gráfico de atividade em SVG.
- `skillicons.dev`: ícones técnicos em SVG.
- GitHub Actions: opcional para gerar snake, lista de artigos, status de projetos, cards próprios e outros elementos dinâmicos.
- SVG próprio: recomendado para a versão final, permitindo controlar o visual sem JavaScript.

> Observação: o GitHub sanitiza JavaScript em README. As animações reais precisam ser SVG/GIF ou arquivos regenerados por Actions.
